Синхронизация

Приложение уже работает офлайн на этом устройстве. Для синхронизации между iPhone и компьютером подключи бесплатный Supabase-проект.

Один и тот же Sync ID + те же Supabase данные на обоих устройствах = одна история.
Как подключить Supabase за 3–5 минут
  1. Создай бесплатный проект на supabase.com.
  2. В SQL Editor выполни SQL из файла supabase.sql.
  3. Project Settings → API: скопируй Project URL и anon public key.
  4. Вставь их сюда и придумай одинаковый Sync ID на обоих устройствах.
