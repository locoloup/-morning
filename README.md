# Morning Routine

Готовая PWA для iPhone Safari и компьютера.

## Что есть
- 5 утренних привычек
- автоматический новый день
- история по дням с конкретными выполненными пунктами
- streak
- статистика за 30 дней
- работает офлайн
- можно добавить на Home Screen
- опциональная синхронизация через Supabase

## Быстрый запуск локально
Открой папку через любой статический сервер, например:
python3 -m http.server 8080

Затем открой http://localhost:8080

## Как выложить в интернет
Самый простой вариант: Netlify Drop / Vercel / GitHub Pages.
Загрузи содержимое этой папки — получишь HTTPS-ссылку, которая открывается и на iPhone, и на Mac.

## Как включить sync
1. Создай бесплатный проект на Supabase.
2. Открой SQL Editor.
3. Выполни содержимое `supabase.sql`.
4. Project Settings → API:
   - скопируй Project URL
   - скопируй anon/public key
5. В приложении нажми `•••`, вставь оба значения.
6. Придумай Sync ID и используй тот же ID на втором устройстве.

ВАЖНО: текущая схема рассчитана на личное использование и простой setup.
Sync ID лучше сделать длинным и непредсказуемым.
